# VoiceGen Pro - Professional Text-to-Speech Converter

<!--![VoiceGen Pro Screenshot](./screenshot.png)   -->

VoiceGen Pro is a modern, responsive web application that converts text to speech using the Web Speech API. Designed with a professional UI and built with Tailwind CSS, it offers a seamless experience across all devices.

## Features ✨

- **Natural Speech Synthesis**: Convert any text to natural-sounding speech
- **Voice Customization**:
  - Multiple voice options
  - Adjustable speed, pitch, and volume
- **Visual Feedback**: Real-time word highlighting as text is spoken
- **File Import**: Upload text files (.txt) for conversion
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Modern UI**: Professional interface with Tailwind CSS
- **Speech Controls**:
  - Play/Pause/Resume functionality
  - Stop button to cancel speech

## Technologies Used 🛠️

- HTML5
- CSS3 (Tailwind CSS)
- JavaScript (Web Speech API)
- Font Awesome icons
